# تطبيق عافيتك - Aafiatak App

نظام احترافي لإدارة خدمات التمريض المنزلي، يعمل بثلاث واجهات:

## الواجهات

### 1. واجهة الإدارة (Admin)
- إدارة الخدمات والأسعار (بالريال اليمني)
- الموافقة على بيانات الممرضين
- الموافقة على طلبات المستفيدين
- إضافة طرق الدفع
- تعيين الممرضين للطلبات
- لوحة إحصائيات شاملة
- تغيير كلمة المرور الإجباري عند أول تسجيل دخول

### 2. واجهة الممرض (Nurse)
- تسجيل حساب جديد (الاسم الرباعي إجباري، رقم الهاتف، الموقع، رقم الهوية، رقم رخصة الممارسة، تاريخ انتهاء الرخصة)
- عرض المهام المعينة
- تحديث حالة المهام

### 3. واجهة المستفيد (Beneficiary)
- تسجيل حساب جديد (الاسم، رقم الهاتف، الموقع - جميعها إجبارية)
- تصفح الخدمات المتاحة
- طلب خدمات
- متابعة حالة الطلبات
- عرض طرق الدفع المتاحة

## التقنيات المستخدمة

- **Next.js 15** - إطار العمل الأساسي
- **Firebase Firestore** - قاعدة البيانات (مجانية مدى الحياة - Spark Plan)
- **Tailwind CSS** - التصميم
- **shadcn/ui** - مكونات واجهة المستخدم
- **Zustand** - إدارة الحالة
- **TypeScript** - لغة البرمجة

## التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone https://github.com/ForexYemeni/Aafiatak.git
cd Aafiatak
```

### 2. تثبيت المكتبات
```bash
npm install
```

### 3. إعداد Firebase
```bash
# نسخ ملف البيئة
cp .env.example .env.local

# تعديل الملف وإضافة بيانات Firebase الخاصة بك
# FIREBASE_PROJECT_ID=your-project-id
# FIREBASE_CLIENT_EMAIL=your-client-email@your-project.iam.gserviceaccount.com
# FIREBASE_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\nYOUR_KEY\n-----END PRIVATE KEY-----\n
```

### 4. تشغيل المشروع
```bash
npm run dev
```

### 5. تسجيل الدخول الإداري الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`
- ⚠️ **سيُطلب منك تغيير كلمة المرور عند أول تسجيل دخول**

## إعداد Firebase

1. انتقل إلى [Firebase Console](https://console.firebase.google.com/)
2. أنشئ مشروع جديد
3. فعّل **Firestore Database** (اختر موقع تخزين قريب من اليمن)
4. انتقل إلى **Project Settings > Service Accounts**
5. انقر على **Generate New Private Key** لتحميل ملف JSON
6. انسخ القيم من الملف إلى `.env.local`
